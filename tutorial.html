1

Buat Google Spreadsheet

Buka sheets.new, masuk dengan akun Google, lalu beri nama—misalnya Zigs.fi Data.

Biarkan spreadsheet kosong. Tab accounts, transactions, budgets, goals, debts, settings, dan audit_log dibuat otomatis oleh script.
2

Buka Apps Script dan tempel kode terbaru

  1. Di spreadsheet, pilih Extensions → Apps Script.
  2. Hapus seluruh isi file Code.gs.
  3. Tekan tombol Salin kode di bawah, lalu tempel semuanya.
  4. Tekan Ctrl + S atau klik ikon Save.
Versi terbaru: sync hanya menulis tabel yang berubah, membatasi audit log, dan melewati tabel yang isinya sama. Ini menggantikan script lama yang selalu menulis ulang ketujuh tab.

3

Ganti Spreadsheet ID

Salin ID dari URL spreadsheet. ID adalah teks panjang di antara /d/ dan /edit.

https://docs.google.com/spreadsheets/d/INI_SPREADSHEET_ID/edit

Di bagian atas Code.gs, ganti nilai di dalam tanda kutip:

const SPREADSHEET_ID = "INI_SPREADSHEET_ID";
Gunakan ID spreadsheet milikmu sendiri. Kode yang ditampilkan tetap memakai placeholder agar tutorial aman dipakai semua pengguna.
4

Deploy sebagai Web App

  1. Klik Deploy → New deployment.
  2. Klik ikon roda gigi, lalu pilih Web app.
  3. Isi Description, misalnya Zigs.fi sync.
  4. Pada Execute as, pilih Me.
  5. Pada Who has access, pilih Anyone.
  6. Klik Deploy, lalu selesaikan otorisasi Google.
  7. Salin URL Web App yang berakhiran /exec.
Jika muncul “Google hasn't verified this app”: klik Advanced → Go to project → Allow. Ini script milikmu sendiri yang berjalan di akun Google milikmu.
5

Hubungkan ke Zigs.fi

  1. Kembali ke halaman setup Zigs.fi.
  2. Tempel URL Google Spreadsheet lengkap pada kolom pertama.
  3. Tempel URL Web App /exec pada kolom kedua.
  4. Klik Uji Koneksi.
  5. Jika statusnya valid, klik Simpan & Lanjut.
✓Sheet dapat digunakan terus-menerus tanpa batas periode.
✓Data lokal disalin ke Sheet saat tombol sinkron ditekan.
✓Setelah sync pertama, tabel yang tidak berubah akan dilewati agar lebih cepat.
↻

Jika kode Apps Script diperbarui

Tempel kode baru, simpan, lalu buka Deploy → Manage deployments. Klik ikon Edit, pilih New version, kemudian Deploy. URL /exec tetap sama.

!

Troubleshooting

  • Link Sheet tidak valid: gunakan URL lengkap dari docs.google.com/spreadsheets/d/…
  • URL Apps Script tidak valid: pastikan URL berasal dari script.google.com dan berakhiran /exec, bukan /dev.
  • Tidak bisa terhubung: cek deployment menggunakan Execute as Me dan akses Anyone.
  • Script error saat ping: periksa SPREADSHEET_ID, tanda kutip, dan pastikan spreadsheet belum dihapus.
  • Perubahan kode tidak terbaca: buat New version melalui Manage deployments; menyimpan kode saja tidak memperbarui deployment aktif.
